# CNKH POS Mobile — APK downloads

Android install package for **CNKH POS Mobile** (Flutter companion).

## Download

Use the latest **Release** on this repo (Assets section):

- `CNKH_POS_Mobile.apk` — sideload on Android (enable install from unknown sources)
- `CNKH_POS_Mobile.aab` — Play Store / bundle format
- `CNKH_POS_Mobile_iOS_project.zip` — iOS project for self-signing on Mac
- `IOS_SELF_SIGN.md` — how to sign and export IPA yourself

Desktop POS source remains at: https://github.com/tyz11234/-CNKH_POS_V5

## Version

Companion build aligned with CNKH Hardware POS V5 (`5.0.0-alpha.4` era).
